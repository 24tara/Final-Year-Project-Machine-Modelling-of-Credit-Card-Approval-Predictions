# Final-Year-Project-Machine-Modelling-of-Credit-Card-Approval-Predictions

project title: Machine Learning Modelling of Credit Card Approval Predictions

Credit card approval plays a vital role in modern digital and financial risk management. Good credit scores allow for customers to apply for credit cards which can help them secure a loan. Current manual systems are slow and may be biased. Machine learning models provide fast and fair data decision predictions. Additionally, current systems lack clear interpretations as to why customers may be declined credit card approval.
